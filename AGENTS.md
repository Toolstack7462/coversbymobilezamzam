# Design context

Strategic and visual context for this project lives in two root files:

- **PRODUCT.md** — register, users, purpose, brand personality, anti-references,
  design principles, accessibility commitment. Read it before any design work.
- **DESIGN.md** — the visual system: tokens, palette, type scale, elevation,
  components, and the do/do-not list. Follows the Stitch DESIGN.md format.

The one-line version: this is a **brand** surface for a real shop in Sulmona,
and its job is to make a stranger believe an unknown Italian shop is real and
competent. Proof outranks polish; nothing renders from data that does not exist.
